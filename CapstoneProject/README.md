# Project Plan

## Project Overview

This project explores how workplace AI adoption relates to productivity, burnout, innovation, perceived job replacement risk, and business return-on-investment signals. The project uses multiple CSV datasets, a PostgreSQL database, an Airflow loading pipeline, exploratory analysis in Jupyter, machine learning models, and a Dash dashboard.

### Questions
1. How have emerging AI tools improved worker efficiency, if at all?
2. Is adopting AI tools in the workplace effecting employee burnout? Making it worse or better?
3. Is there an optimal balance between AI use and manual coding time?
4. Is AI adoption giving companies an adequate return on investment for it to be worth it?
5. Does AI help to increase innovation?
6. Which job roles feel most threatened by AI replacement?
7. Is AI adoption increasing employee stress or alieviating it?
8. Which industries seem to be beniefiting the most from AI?
